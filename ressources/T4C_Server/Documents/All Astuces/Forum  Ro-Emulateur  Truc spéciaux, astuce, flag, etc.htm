-Escaliers teleporteurs:
BOn, j'vais tenter de vous expliqué ça. Pour faire un escalier, on procède en 2 étapes. On commence par dessiner l'escalier et ensuite on le fais téléporter. Commencer par ouvrir votre map client en BMP et d'aller voir à un endroit où il y a déjà un escalier (C.F. Le temple de LH). Vous allez voir que l'escalier côté client est représenté par une seule pixel. Vous notez le R.V.B (Rouge-Vert-Bleu (La couleur quoi)) de cette pixel. Ensuite, vous mettez cette pixel ou vous voulez et sa ajoutera un escalier. Ensuite, il faut faire la même chose avec la map serveur : Pour qu'il y est une collision sur ton escalier. Pour faire un teleport, tu utilise l'éditeur de Chaotikmind (Merci ) et tu va dans la section téléport. Suffis d'ajouter les coordonnés de ton escalier + ceux d'où tu veux te téléporter. Je suis pas certain que l'éditeur de Chaotikmind permette de mettre des nouveaux teleports pour l'instant, mais au pire vous pouvez toujours aller l'ajouter directement dans le t4c world.wda.

-Porte Teleporteuse:
Pour la porte qui empêche de passer avant un certain level, c'est tout a fait possible via notre éditeur de Vircom préféré. Il suffit de faire une porte qui téléporte de l'autre côté (Comme celle au fond du temple), car de toute façon une porte qui ouvre serait débile, car un ami qui a le niveau requis pourrait ouvrir la porte à un level 1 qui pourrait renaître ensuite. Comment faire cette porte? Tu commence par créer l'item Porte. Ensuite, tu lui met un sort qui s'active avec On Disturbed (Quand tu clique dessus). Ce sort, active un autre sort (Spell Hook) de cette manière :

-Hooked Spell : Le nom du2ième sort qui se fait activer par le premier.
-Hook : On Timer
-Hook Chance% : if(self.level>=X?100:0) X représente le level minimum pour que la porte téléporte
-Initial Delay : 1000

Le deuxième sort sera activé seulement si le personnage est du level X ou plus. COmme tu l'as sans doute deviné, tu programme le deuxième sort pour qu'il téléporte de l'autre côté de la porte.

Le sanctuaire peut etre changer à l'aide de la forumle : (X * 1048576) + (Y * 256) + W
Exemple :

Nom Drizzt
Initial text : Blabla
Défaut text : Blabla
Sanctuaire :
Code:
If(target.viewflag(31001)=0 ) // On vérifie ici si son sanctuaire est deja a cet endroit)

If(Target.viewflag(31001)=1 )

20041 < 0 (self.air < 100) => resistance air reduite
20041 > 0 (self.air > 100) => resistance air boosté
