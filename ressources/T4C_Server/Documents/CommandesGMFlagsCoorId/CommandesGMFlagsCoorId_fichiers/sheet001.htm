Commandes GM Assistant
Remarque: Pour summoner le GM Assistant, vous devez taper: summon monster GMASSISTANT at x,y,world
Commande Description
Last USER Cette commande vous dit quelle est le dernier utilisateur du GM assistant !
SHOUT <text> Cette commande vous permet d'envoyé un message a tout les utilisateurs lors d'une animation par exemple.
DELETE OR SELF-DESTRUCT Cette commande fait disparaître le Gm assistant ! Il s'auto detruit !
SET PORTAL [a -z] TO x,y,z (coordonnée) Cette commande configure un portail dynamic utilisable., il y a 26 portail dynamique au total. Du portail a au z tout ces portail peuvent etre utilisé independement chacun pour teleporté a une location differentes ! Ces portails doivent d'abord etre summon par la commande #summon monster par exemple : #summon monster portalX at 2500,500,0, cela summonera un portail X au coordonée 2500,500,0 (petit intro : il n'y a pas d'espace entre « portal » et « X », le portail sera la et fonctionnera durant toute la durée que le serveur sera allumé. (a moins de le vaporisé.), si un joueur entre dans le portail alors qu'il n'est pas configuré il sera teleporté a son sanctuaire !
NOTE : si il n'y a pas d'espace entre les coordonnées la commande ne marchera pas. Exemple :summon monster PortalX at 1000, 1000, 0 (commande gm normale.)
Set Portal X to 2000 2000 0 (commande gm par le Gmassistants !)
SET PORTAL [a-z] REWARD [XP/GP] TO <valeur> Cette commande configura un portail qui donnera de l'xp ou de l'or. Par exemple : Summon monster PortalX at 1000, 1000, 0 (commande gm normale) ensuite : SET Portal X REWARD XP TO 1000
SET MONSTER [1-4] TO [1-50] [l'id du monstre ] Cela vous permet de pre programmé un summon de plusieur monstre (bcp) vous pouvez grace a cette commande summon un total de 4 sorte de monstre et summon 50 monstre par sorte.
Example: SET MONSTER 1 TO 5 Kilhiam << ca summonera 5 fois le npc khiliam au parametre 1
Attention les portails dynamique peuvent etre la cause de crach du serveur .
LIST MONSTERS Cette commande permet de savoir tout les monstre qui on ete parametré
RESET MONSTERS Cette commande est utilisé pour effacé tout les parametres
MASS SUMMON x1 y1 x2 y2 cette commande permet de faire de multiple spawn a plusieur endroit, il faut au prealable avoir utilisé la commande « set monster » avec le GM assistants !

Example: MASS SUMMON 1300 2000 1400 2050.
