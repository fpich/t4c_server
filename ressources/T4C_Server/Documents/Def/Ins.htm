. IF (Si)

Cette instruction marque le commencement d'une condition. Le code entre IF et son rapport assorti END est exécuté une fois si la condition indiquée dans IF est vraie.

Paramètre(s)

Expression Conditionnelle: C'est une formule de boost. Le bloc de code sera exécuté seulement si c'est vrai.

. ELSE IF (Sinon…si)

Cette instruction marque le commencement d'une condition supplémentaire dans le cas où une condition précédente n'a pas été rencontrée. Le code entre ELSE IF et on rapport assorti END n'est exécutable qu'une fois, si la condition indiquée est vraie.

Paramètre(s)

Expression Conditionnelle: C'est une formule de boost. Le bloc de code sera exécuté seulement si c'est vrai.

Remarque

Cette instruction est essentiellement la même:

IF ( Conditional )

ELSE
            IF ( Conditional )

      ENDIF

ENDIF

. ELSE (Sinon)

Cette instruction marque le commencement d'une sélection d'instructions à être exécuté quand la condition indiquée dans le rapport (IF) si l'action est fausse, plutôt que vrai.

. FOR (POUR)

Cette instruction marque le commencement d'une boucle faite par incrémentation la Valeur de Départ par 1 jusqu'à la Fin la de la Valeur est atteinte. 

Paramètre(s)

Variable: Le nom de la variable

Valeur de départ: Une formule de boost définissant la valeur de départ

Valeur de fin: Une formule de boost définissant la fin valeur

Remarque

         La déclaration “END FOR” est toujours compléments d’instruction.

. WHILE (Tant que)

Cette instruction montre le commencement de l'événement conditionnelle : "loop" (permet de relancer plusieurs fois un même code), commandant de ce fait les fluts de code contenue dans le block d'instruction "WHILE" (tant que...). le code situer entre l'instruction "While" et la marque "END" (fin de commande) est une action répéter tant que la condition spécifier est vrais.

Paramètre(s)

Expression Conditionnelle: C'est une formule de boost. Le bloc de code sera exécuté jusqu'à ce que cette condition ne soit plus vraie.

Remarque

         Le rapport "END WHILE" complète toujours une instruction.      

. Nomination

Cette instruction assigne une valeur à une variable.

Paramètre(s)

Variable: C'est le nom de la variable qui sera disponible dans le PNJ par le var() la variable formule de boost.

Value: C'est une Formule de Boost qui sera utilisée pour calculer une valeur à laquelle la variable sera mise.

. GiveItem (DonnerObjet)

Cette instruction donne des objets choisis aux joueurs.

Paramètre(s)

         Item To Give: C'est un objet choisi de la liste déroulante d'objets.

Remarque

Cette instruction contourne la limite d'encombrement; on donnera l'objet aux joueurs même s'ils sont surchargés. 

 

. GiveXP (DonnerXP)

Cette instruction donne aux joueurs la quantité de points d'expérience indiqués dans le paramètre.

Paramètre(s)

XP To Give: C'est une formule de boost spécifiant la quantité d'expérience indique donné aux joueurs. Si cette valeur est négative, les points d'expérience seront soustraits des joueurs.

Remarque

Les joueurs ne peuvent pas perdre un niveau en perdant des points d'expérience.

. SetFlag (SelectionFlag)

Cette instruction met un flag particulier aux joueurs avec une valeur indiquée.

Paramètre(s)

Flag to set: C'est un flag choisi dans la liste des flags. Si un flag exigé n'existe pas, vous pouvez le créer en utilisant l'éditeur de flag.

The flag's value: C'est une formule de boost qui a l'habitude de calculer une valeur à laquelle le flag sera mis.

. HealPlayer (GuérirJoueur)

Cette instruction guérit des joueurs par le nombre de points de vie indiqués dans le paramètre.

Paramètre(s)

HP To Heal: C'est une formule de boost spécifiant la quantité des points de vie qui doivent être guéris.

. SayText (DireTexte)

Cette instruction est faite pour que les PNJs communiques avec les joueurs.

Paramètre(s)

         Texte: Les mots qu'un PNJ dit aux joueurs.

Remarque

Les mots-clés doivent être entourés par des guillemets ("") pour être mis en évidence dans le speech du PNJ.

. BreakConversation (CasserConversation)

Cette instruction finit les conversations entre les PNJs et les joueurs. Si les joueurs veulent parler aux PNJs de nouveau, ils devront re-cliquer sur les PNJs. Tout les PNJs doivent avoir au moins un "BreakConversation" l'utilisation du keyword(mot-clé) "Adieu".

Remarque

Les joueurs ne peuvent plus faire défiler le texte d'un PNJ une fois qu'une conversation est terminée. Donc, les PNJs doivent dire pas plus que 5-6 mots avant que l'on ne rencontre un "BreakConversation"; autrement les joueurs ne seront pas capables de voir la fin du speech(discours) du PNJ.

. FightPlayer (CombattreJoueur)

Cette instruction est fais pour que les PNJs attaquent les joueurs. Les PNJs resteront agressifs tant que les joueurs laisserons la scène.

Remarque

Cette instruction finit aussi des conversations. Donc, les PNJs doivent dire pas plus de 5-6 mots avant que l'on ne rencontre la commande du combat; autrement les joueurs ne seront pas capables de voir la fin du speech(discours) du PNJ.

. TakeItem (PrendreObjet)

Cette instruction enlève des objets choisis aux joueurs.

Paramètre(s)

         Item To Take: C'est un objet choisi de la liste déroulante d'objets.

. Teleport

Cette instruction téléporte des joueurs aux coordonnées définies dans les paramètres.

Paramètre(s)

X Position: C'est une formule de boost indiquant la coordonnée d'axe X. La valeur doit être entre 1 et 3072.

Y Position: C'est une formule de boost indiquant la coordonnée d'axe Y. La valeur doit être entre 1 et 3072.

World: C'est une formule de boost indiquant le monde. La valeur doit être 0, 1 ou bien 2.

Remarque

Si les joueurs sont envoyés dans une structure de blocage (exemple à l'intérieur d'un mur), ils peuvent être bloqués. Utilisez des coordonnées statiques (par exemple : 1400,400,0) est plus sûr..

. CastSpell (JeterSort)

Cette instruction fais par les PNJs permet de jeter des sorts spécifiques.

Paramètre(s)

Spell To Cast: C'est le sort, choisi de la liste déroulante des sorts, qui seront lancés.

. CastSpellOnNPC (JeterSortSurPNJ)

Cette instruction fais par les PNJs permet de jeter des sorts spécifiques sur eux.

Paramètre(s)

Spell To Cast: C'est le sort, choisi de la liste déroulante des sorts, qui seront lancés.

. GiveGold (DonnerOr)

Cette instruction donne aux joueurs la quantité d'or indiqué dans le paramètre.

Paramètre(s)

Gold To Give: C'est une formule de boost spécifiant la quantité d'or que l'on doit donner.

. TakeGold (PrendreOr)

Cette instruction retire des joueurs la quantité d'or indiqué dans le paramètre.

Paramètre(s)

Gold To Take: C'est une formule de boost spécifiant la quantité d'or qui doit être pris.

Remarque

Si les joueurs n'ont pas assez d'or, tout l'or qu'ils ont sera pris. S'ils n'ont pas d'or, rien ne sera pris.

. DisplayItemsSoldByNPC (AfficherObjetsVenduParPNJ)

Cette instruction montre l'interface "Acheter" des PNJs aux joueurs; il inscrit tous les objets que les PNJs peuvent vendre.

Remarque

La fenêtre "Editer marchand" doit être configuré; autrement les PNJs n'auront rien à vendre. Double-clic sur cette instruction pour ouvrir la fenêtre "Editer marchand".

. DisplayItemsBoughtByNPC (AfficherObjetsAcheterParPNJ)

Cette instruction montre l'interface "Vendre" des PNJs aux joueurs; il inscrit les tous les objets du joueur que le PNJ désire acheter.

Remarque

La fenêtre "Editer marchand" doit être configuré; autrement les PNJs ne serons pas intéressés par les objets des joueurs. Double-clic sur cette instruction pour ouvrir la fenêtre "Editer marchand".

. DisplayTrainedSkills (AfficherEntraînerCompétences)

Cette instruction montre l'interface "Entraîner compétence" des PNJs aux joueurs.

Remarque     

la fenêtre "Editer entraîneur" doit être configuré; autrement les PNJs n'auront rien à entraîner. Double-clic sur cette instruction pour ouvrir la fenêtre "Editer entraîneur".

. DisplayTaughtSkills (AfficherApprendreCompétences)

Cette instruction montre l’interface “Apprendre compétences/sorts” des PNJs aux joueurs.

Remarque

La fenêtre "Editer entraîneur" doit être configuré; autrement les PNJs n'aurons pas de compétences/sorts à apprendre. Double-clic sur cette instruction pour ouvrir la fenêtre "Editer entraîneur".
